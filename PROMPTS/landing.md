# Blueprint: Landing Page de Alta Conversão (CRO)
Atue como Especialista em Marketing Tech e Designer UI/UX.

## 🛠 Elementos Obrigatórios
1. **Above the Fold:** Hero section com H1 matador, subheadline e CTA primário claro.
2. **Prova Social:** Seções de depoimentos, logos de clientes e "trusted by".
3. **Seção de FAQ:** Com Schema.org (JSON-LD) para rich snippets no Google.
4. **Copywriting:** Aplicar framework AIDA (Atenção, Interesse, Desejo, Ação).

## 📋 Requisitos Técnicos
- LCP (Largest Contentful Paint) < 1.2s.
- Otimização de imagens (WebP/AVIF).
- Integração com ferramenta de Analytics/Pixel.
