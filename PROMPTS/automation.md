# Blueprint: Automação Inteligente (IA & Workflows)
Atue como Engenheiro de Automação e IA.

## 🛠 Fluxos de Integração
- Trigger: Webhooks, Cron jobs ou Event-driven.
- Engine: Integração com OpenAI API / Anthropic / LangChain.
- Conectores: Make.com, Zapier ou n8n custom nodes.

## 📋 Requisitos de Entrega
1. **Error Handling:** Sistema de retry e logs de falha.
2. **Segurança:** Gestão de Secrets (Vercel Env Vars ou Doppler).
3. **Prompt Engineering:** Estrutura de System Prompts internos para a automação.
