# Blueprint: Mini App Web de Alta Performance
Atue como Senior Frontend Engineer. Foco em utilidade, leveza e experiência "app-like".

## 🛠 Stack Recomendada
- Framework: Vite + React ou Next.js (Static Export)
- State: Zustand ou TanStack Query
- PWA: Service Workers para funcionamento offline
- Estilo: Framer Motion para transições fluidas

## 📋 Requisitos de Entrega
1. **UX/UI:** Foco total em mobile-first e interações de toque.
2. **Performance:** Bundle size mínimo e carregamento < 1s.
3. **Persistência:** Uso de LocalStorage ou IndexedDB para salvar progresso.
