Para "ligar o motor" com autoridade de engenheiro sênior, você deve usar uma frase que ative o reconhecimento de padrão da IA para as instruções que você salvou.

A melhor frase é curta, direta e aciona o Protocolo que definimos. Use esta:

"Ativar Protocolo Arquiteto Sênior: [MÓDULO] solicitado. Analise os requisitos e inicie o Planejamento para o seguinte projeto: [DESCREVA SEU PROJETO AQUI]"



1. [SAAS] (Software as a Service)
Quando usar: Quando for criar sistemas complexos com login, bancos de dados e pagamentos.

Foco da IA: Autenticação, segurança de dados, estrutura de tabelas (SQL) e escalabilidade.

2. [MINIAPP] (Pequenos Apps Web)
Quando usar: Para ferramentas úteis e rápidas (calculadoras, conversores, geradores de PDF).

Foco da IA: Leveza, funcionamento offline (PWA), interatividade rápida e UX mobile.

3. [LANDING] (Páginas de Venda)
Quando usar: Para sites de uma única página focados em converter visitantes em clientes.

Foco da IA: Copywriting (AIDA), gatilhos mentais, velocidade de carregamento extrema e botões de CTA estratégicos.

4. [AUTOMATION] (Automação com IA)
Quando usar: Quando quiser criar scripts que conectam APIs ou usam inteligência artificial para processar dados.

Foco da IA: Integrações de API, tratamento de erros, chaves de segurança e fluxos de trabalho inteligentes.

5. [SEO] (Otimização Técnica)
Quando usar: Quando o foco principal for aparecer no topo do Google.

Foco da IA: Tags semânticas, dados estruturados (JSON-LD), velocidade (Core Web Vitals) e acessibilidade.

Como escolher na hora de digitar?
Imagine que você quer criar um site para a Tintas Qualyquimy.

Se o objetivo for vender um serviço rápido, você usa: [LANDING].

Se o objetivo for um portal para revendedores logarem, você usa: [SAAS].

Se for apenas um simulador de cores, você usa: [MINIAPP].

Dica Sênior: Você pode combinar dois se o projeto for grande. Exemplo:

"Ativar Protocolo Arquiteto Sênior: [LANDING] + [SEO] solicitados..."

Isso diz ao Claude: "Faça uma página que venda muito, mas que também seja perfeita tecnicamente para o Google".
