# 🚀 GUIA RÁPIDO - Como Usar o Sistema

## Você tem 2 formas de criar landing pages:

---

## ✨ FORMA 1: Landing Page para Tintas Qualy Quimy (RECOMENDADO)

### Como usar:

**Passo 1**: Digite qualquer coisa assim:
```
"Crie uma landing page para Seladora Acrílica"
```

**Passo 2**: Sistema faz TUDO automaticamente:
```
✅ Carrega o template Tintas Qualy
✅ Substitui [PRODUTO] = Seladora Acrílica
✅ Gera HTML completo pronto para vender
✅ Gera sitemap.xml
✅ Gera robots.txt
✅ Abre preview no browser
✅ Você aprova e publica
```

### O que você vai receber:

```html
<!-- seladora-acrilica-landing-page.html -->
<!DOCTYPE html>
<html lang="pt-BR">
<!-- 11 seções obrigatórias -->
<!-- SEO otimizado para "Seladora Acrílica + Itaquaquecetuba" -->
<!-- Copy persuasivo focado em WhatsApp -->
<!-- Schema markup completo -->
<!-- Botão WhatsApp flutuante -->
<!-- 100% responsivo -->
</html>
```

### Produtos que funcionam:

```
Seladora Acrílica
Grafiato
Massa Corrida
Textura
Tinta Acrílica Premium
Primer
Verniz Marítimo
Tinta Epoxi
Impermeabilizante
[Qualquer outro produto]
```

## 🎨 FORMA 2: Landing Page Genérica (Para outros negócios)

### Como usar:

**Se NÃO for Qualy Quimy**, diga:
```
"Crie uma landing page"
"Landing page para meu produto"
"Preciso de página de vendas"
```

**Sistema**:
```
✅ Carrega Helena (Landing Page Chief)
✅ Faz perguntas do briefing
✅ Entende seu negócio
✅ Cria estrutura + copy
✅ Personaliza para seu mercado
```

---

## 📋 CHECKLIST - Antes de Usar

- ✅ Sabe qual é o produto?
- ✅ Quer que saia pronto para publicar?

Para **Forma 2 (Genérica)**:
- ✅ Deixa o sistema fazer perguntas
- ✅ Responde com detalhes
- ✅ Aprova no preview

## 💡 DICAS

### Dica 1: Ser Específico
```
❌ "Crie uma landing page"
✅ "Crie landing page para Tinta Acrílica Premium"
```

### Dica 2: Pedir Mudanças Depois
```
Primeira versão: "Crie LP de Seladora Acrílica"
Depois: "Muda o CTA para 'Solicitar orçamento no WhatsApp'"
```

### Dica 3: Testar Variações
```
"Crie 2 versões do headline"
"Mostre opção A vs opção B"
```

### Dica 4: Entender a Estrutura
```
A página terá 11 seções:
1. Hero + Headline
2. O que é [PRODUTO]
3. Para que serve
4. Onde usar
5. Benefícios
6. Rendimento
7. Economia
8. Como aplicar
9. Dicas profissionais
10. Comparação
11. FAQ + CTA final
```
