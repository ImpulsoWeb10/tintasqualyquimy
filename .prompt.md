## System Rules

1. **Auto-load**: Agent files load automatically when keywords detected
2. **One at a time**: Only one agent active per session (prevents confusion)
3. **File location**: Always reference the file location in responses
4. **Preview always**: After content creation, show preview
5. **Iterate easily**: User can ask for changes without re-briefing
