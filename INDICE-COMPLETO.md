### Passo 1: Abra o chat e digite
```
"Crie uma landing page para [PRODUTO]"

Exemplos:
- Crie LP para Mass PVA
- Landing page de Grafiato
- Crie página para Seladora Acrílica
```

### Passo 2: Sistema faz perguntas mínimas (3-4)
```
Você RESPONDE RÁPIDO ou deixa em BRANCO
```

```

✅ sitemap.xml
✅ robots.txt

🌐 Browser abre preview automaticamente
```
