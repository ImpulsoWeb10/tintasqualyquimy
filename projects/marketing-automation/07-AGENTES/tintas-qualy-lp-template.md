## 7. SCHEMA MARKUP (JSON-LD)

Incluir 3 tipos obrigatórios:

### LocalBusiness
```json
{
  "@context": "https://schema.org",
  "@type": "LocalBusiness",
  "name": "Tintas Qualy Quimy",
  "address": {
    "@type": "PostalAddress",
    "streetAddress": "R. Leiria, 45 - Chácara Cuiabá",
    "addressLocality": "Itaquaquecetuba",
    "addressRegion": "SP",
    "postalCode": "08587-100",
    "addressCountry": "BR"
  },
  "telephone": "+5511954950044",
  "url": "https://tintasqualyquimy.com.br"
}
```

### Product
```json
{
  "@type": "Product",
  "name": "[PRODUTO]",
  "brand": "Qualy Quimy",
  "description": "[Descrição técnica]",
  "offers": {
    "@type": "Offer",
    "availability": "https://schema.org/InStock",
    "priceCurrency": "BRL"
  }
}
```

### FAQPage
```json
{
  "@type": "FAQPage",
  "mainEntity": [
    {
      "@type": "Question",
      "name": "[pergunta]",
      "acceptedAnswer": {
        "@type": "Answer",
        "text": "[resposta]"
      }
    }
  ]
}
```
