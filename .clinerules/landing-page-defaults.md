# Padrão ImpulsoWeb10 para Landing Pages

Sempre usar Tailwind CDN, sempre focar em sites estáticos para GitHub Pages e nunca me entrevistar antes de começar um projeto.
# PADRÕES DE QUALIDADE IMPULSOWEB10

## 1. DESIGN & UI (USER INTERFACE) PREMIUM
- **Espaçamento:** Utilize seções amplas com `py-20` ou `py-24`. O site deve "respirar".
- **Modernidade:** Use bordas arredondadas generosas (`rounded-2xl`) e sombras suaves (`shadow-lg`).
- **Cards de Produto:** Devem ter fundo branco, destaque visual e efeito de hover (`hover:scale-105 transition-all`).
- **Tipografia:** Títulos em `font-extrabold` e cor `text-slate-900`. Parágrafos em `text-slate-600`.

## 2. ESTRUTURA DE CONVERSÃO (COPYWRITING AIDA)
- **Headline:** Foco no benefício (Ex: "Paredes prontas em metade do tempo").
- **Diferenciais:** Seção clara de "Por que escolher a Qualyquimy" com ícones.
- **Segurança:** Seção "Onde NÃO usar" ou "Dicas Técnicas" sempre destacada para evitar suporte desnecessário.
- **CTA:** Botão de WhatsApp flutuante e botões de ação com cores vibrantes que contrastem com o fundo.

## 3. SEO TÉCNICO & PERFORMANCE
- **Semântica HTML5:** Obrigatório o uso de `<header>`, `<main>`, `<section>`, `<article>` e `<footer>`. Proibido excesso de `<div>`.
- **JSON-LD:** Todo projeto de produto DEVE incluir o script de Schema.org (`type: Product`) no `<head>`.
- **Acessibilidade:** Imagens com `alt` descritivo e links com `aria-label`.

## 4. AUTOMATIZAÇÃO DE WORKFLOW (MODO TURBO)
- **Sem Entrevistas:** Não pergunte sobre bibliotecas. Use Tailwind via CDN e estrutura estática por padrão.
- **Auto-Execute:** Aplique as mudanças nos arquivos diretamente (auto-accept). Inicie o código imediatamente após a solicitação.
- **Rodapé Padrão:** Sempre inserir: "Desenvolvedor: [ImpulsoWeb10](https://impulso-web-10.github.io/site/)" em todos os projetos.
- **Resposta:** Seja conciso na comunicação. Menos conversa, mais código pronto.
